## Removed games

### Fruit Ninja

- Files removed: 2 (index.html, cover.jpg).
- Repository evidence: the launcher loads the manifest, font, vendors bundle, and main bundle from a third-party UGS jsDelivr mirror. The folder had no local game runtime assets.
- Source review: the available MIT GitHub project pctroll/webninja describes itself as a proof-of-concept game similar to Fruit Ninja, not the actual Halfbrick game or a maintained official port. No authorized offline build of the original was found.
- Decision: removed the remote-only mirror.
- References: https://github.com/pctroll/webninja ; https://www.halfbrick.com/vr-licensing

### 10minutestildawn

- Files removed: 2 (index.html, cover.png).
- Repository evidence: the launcher sets a remote UGS CDN base URL and fetches split Unity data, WASM code, and WASM framework files at runtime. No Unity build files were local.
- Source review: Flanne's itch.io page still offers a browser-run HTML5 demo, but it provides no source package or license permitting redistribution as a standalone offline mirror.
- Decision: removed the remote-only launcher. This is the 10 Minutes Till Dawn demo; the separate 20 Minutes Till Dawn folder was not touched.
- Reference: https://flanne.itch.io/10-minutes-till-dawn

### Poly Track

- Files removed: 8.
- Repository evidence: the local folder had only the launcher, two bundles, font, manifest, and two SVGs. The previous audit recorded six missing runtime asset references.
- Source review: Kodub's current official v0.6.3 release is hosted on the creator's itch.io page. The local build is not an official source checkout, and no redistribution license/source build was found. Public GitHub copies identified in search are unofficial mirrors/archives, not creator-maintained source.
- Decision: removed the incomplete mirror rather than fill its missing files from an unlicensed copy.
- References: https://kodub.itch.io/polytrack ; https://polytrack-labs.github.io/about/

### Polytrackworksnow

- Files removed: 2 (index.html, cover.webp).

- Source review: the referenced 0.6.0 repository is an unofficial mirror; no creator-authorized redistribution source was found.
- Decision: removed the proxy-dependent launcher.
- Reference: https://kodub.itch.io/polytrack
