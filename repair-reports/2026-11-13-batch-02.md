## Removed games

### Hollowknight

- Files removed: 2 (index.html, cover.avif).
- Repository evidence: the only launcher hides the game until Play is clicked, then loads the emulator from jsDelivr and a GBA ROM from a separate jsDelivr repository. No emulator, ROM, or game runtime was stored locally.
- Source/rights review: the current WebAssembly reconstruction found at https://dezm0n.itch.io/hollow-knight-web-port is explicitly unofficial and states that original Hollow Knight artwork/audio remain © Team Cherry. It is not a redistributable official offline build.
- Decision: removed the remote emulator/ROM launcher rather than preserve an unauthorized or non-offline placeholder.
- References: https://www.hollowknight.com/ ; https://dezm0n.itch.io/hollow-knight-web-port

### 1v1.LoL

- Files removed: 48 (6.07 MB).
- Repository evidence: the folder contains a Unity WebGL launcher plus Firebase authentication/Firestore scripts and many unrelated _external assets. Its game runtime depends on a remote service.
- Source/status review: the original operator's status page says 1v1.LOL permanently shut down on 3 November 2025. The community revival rebuilds matchmaking and game servers; it is not an offline build.
- Decision: removed the unusable server-dependent client and its bundled third-party asset clutter.
- References: https://1v1lol.statuspage.io/ ; https://1v1lol.me/1v1-lol-faq/

### Idle Mining Empire

- Files removed: 2 (index.html, cover.jpg).
- Repository evidence: the launcher loads game.js, game.css, and graphics from a third-party jsDelivr mirror; no game runtime files were local.
- Source review: the game is attributed to MarketJS; no authorized source repository or redistributable offline build was found.
- Decision: removed the remote-only launcher.
- Reference: https://www.crazygames.com/game/idle-mining-empire

### BitLife

- Files removed: 2 (index.html, cover.png).
- Repository evidence: the launcher loads UnityLoader, the game JSON, and Unity assets from a third-party jsDelivr repository; the local folder contained no game build.
- Source review: Candywriter's official BitLife site identifies the original game and points to its official app distribution. No official browser build/source package was found; third-party browser copies are not authorized upstream builds.
- Decision: removed the third-party Unity launcher.
- References: https://candywriter.com/ ; https://bitlifeapp.com/

### Littlealchemy2

- Files removed: 2 (index.html, cover.png).
- Repository evidence: the launcher sets its base URL to a third-party jsDelivr copy and loads all app scripts, CSS, fonts, and game data remotely. No game runtime files were local.
- Source review: no official redistributable source build or license for the third-party mirror was found.
- Decision: removed the remote-only launcher instead of treating a third-party CDN copy as an offline game.
- Reference: https://littlealchemy2.com/
