# Offline repair/removal audit — batch 02 (2026-11-19)

## Scope
Six existing FNAF launcher folders were reviewed and removed. None was counted as a repaired game.

## Removed folders
- Five Nights at Freddy's
- Five Nights at Freddy's 2
- Five Nights at Freddy's 3
- Five Nights at Freddy's 4
- Five Nights at Freddys Ultimate Custom Night
- FNaF_ Ultimate Custom Night

## Repository evidence
The five standard FNAF launchers reference a remote base on `cdn.jsdelivr.net/gh/blazerida/fnaf@latest` (game-specific folders), plus a remote JSZip CDN. Their local folders contain runtime/main/style/favicon files but not the complete game data. The alternate UCN folder is a two-file cover/index launcher that also references the remote game host.

The upstream `blazerida/fnaf` repository:
- https://github.com/blazerida/fnaf
- Updated 2026-10-30; no LICENSE file and no GitHub license metadata.
- Its README lists browser demos and is not a redistribution grant for Scott Cawthon's game data.

The original FNAF game and franchise rights are held by Scott Cawthon; a WIPO decision describes the games and trademarks as owned by him and licensed through Scottgames:
- https://www.wipo.int/amc/en/domains/decisions/text/2017/d2017-2379.html
- https://github.com/gamejolt/dmca/blob/main/2017/2017-02-02-scott-cawthon.md

## Files removed
Folder-level deletion removed all files under these six entries, including cached runtime JavaScript and covers. The files were incomplete remote-hosted game wrappers, not complete offline game packages.

## Verification
- Method: inspected each folder tree and all six index.html files; confirmed remote game bases, CDN JSZip, or a two-file launcher, plus missing licensed game-data source.
- Browser/offline gameplay tests: NOT RUN (no local browser runtime or network-capable checkout in this automation environment).
- No game is counted as fixed.

## Preserved for further review
- Five Nights at FrickBears 3 was not touched; it has a complete local WASM/data build and needs gameplay/license review.
- Do-Not-Take-This-Cat-Home and 20 Minutes Till Dawn remain untouched.
