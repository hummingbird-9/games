# Repair batch 03 — 2026-11-21

## Games removed as incomplete/unlicensed cached builds

### Slope
- **Files removed:** 11.
- **Repository evidence:** the launcher sets an external CDN `<base>`, then fetches split Unity data parts plus remote WASM code/framework. The cached `_ext` tree contains UnityLoader and template assets only; it does not contain the Unity data payload or WASM binaries.
- **Source research:** [truubo/slope-offline](https://github.com/truubo/slope-offline) and [ReznorsRevenge1/slope](https://github.com/FinnBaltazar1111/slope) advertise offline single-file builds but no clear redistribution license was found. [Z10P/slope](https://github.com/Z10P/slope) is an unlicensed clone. [NvccTechClub/Slope-Game](https://github.com/NvccTechClub/Slope-Game) is a desktop LWJGL/Gradle remake, not a browser build. No licensed complete web build found.

### Recoil
- **Files removed:** 10.
- **Repository evidence:** the launcher has an external CDN `base` to a Fancade cache, loads a cached game-specific JavaScript/WASM bundle and includes a Poki SDK. These are cache/rip files, not an upstream source build.
- **Source research:** [Fancade's web documentation](https://www.fancade.com/wiki/Fancade_Web) describes the platform's web app and game-link format. [BitcoderCZ/Fancade_Loader_Lib](https://github.com/BitcoderCZ/Fancade_Loader_Lib) is an MIT C# library for loading/editing Fancade games, not an authorized source for the specific Recoil game by Martin Magni. No game-level redistribution license found.

### Idle Mining Empire
- **Files removed:** 9.
- **Repository evidence:** launcher uses a remote CDN base and a cached third-party mirror, includes Poki SDK, and the local folder is a cached portal copy rather than a build with provenance/license.
- **Source research:** [ReallyBasicGames/Idle-Mining](https://github.com/ReallyBasicGames/Idle-Mining) is a different incremental game (CC BY-NC 4.0), not the original Idle Mining Empire. [Breezusmoon/idle-mining-empire](https://github.com/Breezusmoon/idle-mining-empire) is an incomplete Godot/Web3 project with no redistribution license or complete offline web release. No legitimate offline build for this exact game found.

### Fruit Ninja
- **Files removed:** 108.
- **Repository evidence:** launcher uses a remote CDN base, remote 22.6 MB vendor bundle, and Poki SDK; the cache contains game-specific assets (textures, sound, font) from the game-ripping repo `bubbls/UGS-Assets`, with no redistribution license. The cached copy cannot be accepted as a legitimate source build.
- **Source research:** [Brackeys/Fruit-Ninja-Replica](https://github.com/Brackeys/Fruit-Ninja-Replica) is a permissively described Unity replica project, but not a ready WebGL build and doesn't provide a licensed copy of Halfbrick's original game/assets. [Mohammed-Benotmane/Fruit-Ninja-Replica](https://github.com/Mohammed-Benotmane/Fruit-Ninja-Replica) is also a Unity project, not a verified offline browser build. A historic [Halfbrick DMCA notice](https://github.com/cirosantilli/dmca-fork/blob/master/2011-10-25-halfbrick.markdown) specifically challenged a Fruit Ninja clone using the original game's copyrighted designs/assets; I therefore did not substitute copied assets.
