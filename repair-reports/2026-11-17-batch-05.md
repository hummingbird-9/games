# Offline game repair — batch 05 (2026-11-17)

This batch fixes the site's iframe loading model, repairs the shared Ruffle runtime used by 15 Flash games, and removes two entries that do not have complete, redistribution-cleared offline browser builds.

## Site-wide iframe fix

Updated `hummingbird-9/hummingbird-9.github.io/games.html` (commit `345512f4443913db8c5ac7599020f0bd151b693b`).

The Games page previously fetched each game's HTML, injected a `<base>`, and placed the result in `iframe.srcdoc`. That gives the game document an `about:srcdoc` origin. Construct 3 games then attempted to start workers from `file:///scripts/dispatchworker.js`, which browsers reject.

The player now sets the iframe's `src` to the game's real jsDelivr URL. The Open in new tab action uses the same direct URL. This preserves the real game origin and makes relative scripts, workers, assets, and service-worker scopes resolve as normal URLs.

### Direct-URL comparison

|---|---|---|

This confirms a shared iframe-loading problem, not four independent game-code failures. Some of the pages still report individual missing sounds, JSON, or other assets, so this is not gameplay certification.

## Shared Ruffle repair — 15 games

The local Ruffle build had a bad public asset base. It tried to load WASM from a duplicated `_ext/...` URL, and its two core JavaScript chunks were missing from each game folder.

For all 15 games below:
- Added the two matching Ruffle core JavaScript chunks to the game folder.
- Configured Ruffle's public path to the game folder.
- Switched the Ruffle loader to the locally cached `_ext` copy.
- Added full-height iframe sizing to the wrapper.

### Verification

The 15-game Playwright run passed for every title in both a normal tab and an iframe. For each, the Ruffle player was visible at 1280×800, the Ruffle WASM and SWF requests returned HTTP 200, and no fatal page errors were recorded.

This verifies player/runtime loading. It does not prove every level, control, sound, or gameplay feature has been tested. The SWF files are still hosted from their existing external source URLs, so these entries are not yet fully offline.

Ruffle license texts and the source notice are now stored under `third-party-licenses/Ruffle/`.

## Removed as unrecoverable

- **Angry Birds Chrome** — the available source is an unofficial copy of a proprietary Rovio title with no verified redistribution license; the folder also lacked the complete runtime/asset set.
- **Bloxorz** — the entry was only a wrapper around a remotely hosted commercial SWF. No complete license-cleared offline browser build was found; the open-source candidate identified was a desktop project, not a browser port.
