# Offline repair batch 2 — 2026-11-14

This batch removed eight broken remote launchers for which no legitimate, redistributable offline build was found. No replacement was imported merely to fill a slot.

## Removed as unrecoverable

| Folder | Reason |
|---|---|
| 1v1lol | Online multiplayer title; no offline game server or authorized source build. The available copy/clone is not an authorized offline port. |
| bitlife | The official BitLife site points to app stores, not a browser build. A BitLife-style GitHub clone exists, but it has no license and is not the original Candywriter game. |
| doge-miner | No maintained source build of the original game found. DogeminerCE is a remake of DogeMiner 2; its separate asset license restricts use to non-commercial derivative works and prohibits re-uploading the unmodified game/assets as your own product. |
| fruit-ninja | No current maintained licensed port found. The MIT WebNinja project is a 2013 proof-of-concept; newer Fruit Ninja-style clones found have no redistribution license. |
| idle-mining-empire | Prior audit found an external-CDN-only launcher; no complete authorized offline source build was found. |
| poly-track | No authorized source build found. The official game is proprietary; the available fan clone has no license granting redistribution. |
| 10-minutes-till-dawn | Official game is available on itch.io, but no authorized public source build or redistributable offline port was found. |
| hollow-knight-silksong | Only a remote launcher was present; no authorized offline web source build from Team Cherry was found. |

## Research references

- BitLife official site: https://bitlifeapp.com/ — links to official mobile distribution, not a browser build.
- BitLife-style clone: https://github.com/jmrothberg/BitLife — repository has no license file; not an authorized Candywriter build.
- DogeminerCE code and asset terms: https://github.com/DogeminerCE/DogeminerCE/blob/main/Asset%20License — asset license limits use and prohibits re-uploading unmodified assets as one's own product.
- Old MIT Fruit Ninja-style proof of concept: https://github.com/pctroll/webninja — last updated in 2013 and described by its authors as a proof of concept.
- Recent Fruit Ninja-style clones: https://github.com/carlomigueldy/fruit-ninja-three and https://github.com/PanduTechLab/Fruit-cutter-game — neither repository includes a redistribution license.
- 10 Minutes Till Dawn official web listing: https://flanne.itch.io/10-minutes-till-dawn — no source archive or redistribution license was found.
- 1v1.LOL copy: https://gitlab.com/Schwonks/1v1-lol — explicitly described by its author as a copy to unblock the game, not an official source build.
