# Offline repair batch 08 — 2026-11-17

## Outcome

Removed five incomplete entries that could not be made into legitimate offline games from the available material. No replacement builds were imported.

## Per-game findings

### Snowbattle.io — removed
- Existing tracked files: 11 (736,511 bytes).
- The launcher points to a remote Unity package. The local tree contains a loader/config/template fragments but no Unity data or WASM game payload. It also depends on an online multiplayer service.
- Source search: [Y8's game listing](https://www.y8.com/games/snowball_io) identifies Gamebiz as developer and describes play with friends/online players. No redistributable source build was found.
- Result: removed as unrecoverable for this offline collection.

### Slither.io — removed
- Existing tracked files: 3 (693,188 bytes).
- The HTML depends on remote Gulper.io multiplayer servers and external advertising/analytics services; the folder has no local game engine or server implementation.
- Source/rights research: [Slither.io's Terms of Service](https://slither.io/tos/) identifies Lowtech Studios LLC and describes a proprietary, confidential, nonpublic network protocol; it expressly prohibits reverse engineering or duplicating the service.
- Result: removed as unrecoverable for an offline-only collection. A local Snake clone would not be the same game, so none was substituted.

### Solar Smash — removed
- Existing tracked files: 7 (306,597 bytes).
- The launcher uses a remote base URL and YouTube Playables API. The tracked folder contains template fragments only; the actual Unity loader/data/WASM game build is absent.
- Source/rights research: [Apple's official Solar Smash listing](https://apps.apple.com/us/app/solar-smash/id1495723103) identifies PARADYME LIMITED as developer and © Paradyme Limited. No source or redistribution license for the web build was found.
- Result: removed as unrecoverable for this offline collection.

### Sonic 1 — removed
- Existing tracked files: 4 (10,649,714 bytes).
- The Emscripten loader requests `index.data` (38,197,592 bytes) from an external R2 host; that file is not tracked. The page also references missing `css/fonts.css` and registers an absent service worker.
- Source/rights research: [Sega's registered Sonic the Hedgehog trademark](https://www.trademarkia.com/sonic-the-hedgehog-78333551) identifies SEGA CORPORATION as owner. No licensed redistribution permission for the game assets/data was found.
- Result: removed as unrecoverable for this offline collection.

### Sonic-1-WASM-main — removed
- Existing tracked files: 2 (1,779,305 bytes).
- This is an incomplete duplicate launcher: only `index.html` and a cover are tracked; its referenced JS/WASM and supporting assets are absent. It has the same Sonic rights issue described above.
- Result: removed as unrecoverable for this offline collection.
