# Offline game repair — batch 04 (2026-11-17)

This batch checked five entries that had clear structural failures. All five folders were removed rather than left as non-working launchers. The catalogue now contains 199 game `index.html` pages.

## Removed

- **Drive Mad** — its entire `index.html` was only a 72-byte JSON response (`{"ISO":"US","ccpaApplies":true}`), not a game page. The folder contained no game runtime or game assets.
- **Geometry Dash** — the launcher pointed to `index-normal.html` and `index-lowram.html`, but neither file existed. The folder contained no playable game build.
- **Block Blast** — its Unity page referenced `Build/BlockBlast1.1-8.loader.js`, `.data.unityweb`, `.framework.js.unityweb`, and `.wasm.unityweb`; the entire `Build/` directory was absent. Only the launcher and Unity template UI files were present.
- **BlockPost** — its cached Unity configuration required `webgl_poki.data.unityweb`, `webgl_poki.wasm.code.unityweb`, and `webgl_poki.wasm.framework.unityweb`, none of which were in the folder. The existing entry also relied on external multiplayer/Poki services.
- **Plague Inc** — the folder had only its Unity loader and launch pages. The actual 300+ MB WASM/data payload was fetched in remote chunks and was not included locally; no redistribution-cleared offline build was available.

## Kept / not classified as removed

- **BitLife** — retained because the user confirmed that it works. The diagnostic-only offline test could not load its remote Unity payload, but that result does not override the user's working-site confirmation.
- **Bloons TD 2 and Bloons TD 4** — retained. Their page wrappers received explicit full-page sizing so the Ruffle object can fill the site iframe; live-site verification is still pending.
- **Angry Birds Chrome** — retained. The upstream frame-hiding timer was removed so it no longer deliberately hides its content when embedded. This fixes the frame guard, not the remaining remote-asset/offline completeness issue.
- **Bloxorz** — retained. Its wrapper was changed from the unsupported Ruffle `.load()` API to standard `<object>/<embed>` markup. The Ruffle loader and SWF still use external URLs, so offline playback is not yet certified.
- **Awesome Tanks** — its full game scene and iframe runtime were reached in the browser; actual movement/fire controls still need a definitive assertion.

## Audit limitation

The full-catalog smoke test covered 204 pages in a normal tab and a same-origin iframe. It used a diagnostic stub for `/game-capture.js`, because that production helper is supplied by the live site and is not in this repository. Consequently, pages that depend on the live helper or remote asset rewriting may be reported as missing dependencies even if they work on the deployed site. The automated scan is a triage report, not a definitive “broken game” count and not gameplay certification.

No games were removed solely because the smoke test reported failed images, sounds, ads, analytics, or other optional requests. The next batch should use the deployed site's actual capture/proxy behavior when testing those games.
