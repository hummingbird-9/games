# Ruffle self-hosted runtime

Ruffle JavaScript runtime and WASM files mirrored into game folders are sourced from:

- https://github.com/u-cvlassrom-y/google

The bundled distribution includes the Ruffle MIT and Apache-2.0 license texts in this folder.
The two `core.ruffle.*.js` chunks copied into the games are part of the same upstream self-hosted runtime.

Ruffle is an open-source Flash Player emulator. The game SWF files are separate third-party content and are not relicensed by these notices.
